# Context On Tabs

Context On Tabs is a Manifest V3 browser extension scaffold for creating floating AI context panels from highlighted webpage content.

## What is included

- Plasmo + React + TypeScript extension setup
- TailwindCSS styling
- Content-script overlay injection
- Text selection capture and source anchoring
- Floating, draggable, resizable panels
- Local graph persistence through Chrome Storage
- Background service-worker AI request routing
- Popup status view and local graph reset

## Development

```bash
npm install
npm run dev
```

Then load the generated development extension from `build/chrome-mv3-dev` in `chrome://extensions`.

This project expects Node 20-24. Plasmo `0.90.5` uses Parcel `2.9.3`; the root `package.json` pins those Parcel internals through `overrides` so npm cannot accidentally hoist newer incompatible Parcel packages.

If you previously installed dependencies with newer Parcel overrides(Happens), refresh the install:

```bash
rm -rf node_modules package-lock.json .plasmo/cache
npm install
npm run dev
```

If Node is installed through `fnm` but `npm` is not on the current shell path, use the installed Node bin path directly:

```bash
PATH=path/to/node_binary:$PATH npm run dev
```

## Build

```bash
npm run build
```

The production extension output is generated by Plasmo under `build/`.

## AI key

The scaffold reads `OPENAI_API_KEY` during local builds. A browser extension bundle is not a safe place for private API keys, so use this only for local MVP testing and move production calls behind a backend service.
